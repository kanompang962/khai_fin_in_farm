# รางน้ำไก่ PVC 2″

ยาว

วาล์วปิด ระดับน้ำ **3.4** ซม. ในราง **3.0** ลิตร

ลากเพื่อหมุน · ล้อเมาส์/บีบนิ้วเพื่อซูม

## 01ขนาดราง

| ท่อ PVC เส้นผ่านศูนย์กลางนอก | 60 มม. (2″) |
| --- | --- |
| ตัดด้านบนออก | \~35% · 126° |
| ปากรางกว้าง | \~5.4 ซม. |
| ความลึกน้ำที่เหมาะสม | 3–4 ซม. |
| ความจุ ราง 1.50 ม. | \~2.5 ลิตร |
| ความจุ ราง 2.00 ม. | \~3.3 ลิตร |
| ไก่ต่อราง 1 เส้น | 20–30 ตัว |
| รางที่แสดงอยู่ | 2.00 ม. |

## 02ชิ้นส่วน

วาล์วมินิกว้างราว 5 ซม. และต้องจมน้ำจึงจะตัดน้ำได้ ใส่ในรางกว้าง 5.4 ซม. ที่น้ำลึกแค่ 3–4 ซม. ไม่ได้ จึงตั้งไว้ในถ้วยพักน้ำ 4″ ที่ต่อถึงรางด้านล่าง ระดับน้ำในถ้วยกับในรางจึงเท่ากันเสมอ

- **1**

  ท่อ PVC 2″ ตัดครึ่งยาว 1.50 หรือ 2.00 ม. ขอบโค้งเข้าด้านในกันน้ำหก
- **2**

  วาล์วลูกลอยมินิ ½″ แบบ Bน้ำเข้าด้านบน ออกด้านข้าง ลูกลอยอยู่ในตัววาล์ว ไม่มีก้านยื่น
- **3**

  ข้อต่อเกลียวใน ½″สำหรับต่อวาล์ว
- **4**

  ข้องอ 90° ½″
- **5**

  ท่อ PVC ½″น้ำเข้าจากภายนอกโรงเรือน
- **6**

  คลิปล็อกท่อ ½″ยึดท่อน้ำเข้ากับเสาหรือขาตั้ง
- **7**

  น้ำยาประสานท่อ PVC / เทปพันเกลียวไม่แสดงในโมเดล
- **8**

  ถ้วยพักน้ำ PVC 4″ + ฝาปิดก้นสูงราว 10 ซม. เจาะรูรับปลายราง 2″ ด้านล่าง

## 03ขั้นตอนประกอบ

1. ตัดท่อ PVC 2″ ตามความยาวที่ต้องการ (1.50 หรือ 2.00 ม.)
2. ตัดด้านบนออกประมาณ 35% ของเส้นรอบวง
3. ลบคมและดัดขอบปากรางเข้าด้านในเล็กน้อย
4. ตัดท่อ 4″ ยาว \~10 ซม. ปิดก้น เจาะรูข้าง เสียบปลายรางด้านที่ไม่ได้ตัดบนเข้าไป แล้วยาซีลให้แน่น
5. ขันวาล์วแบบ B เข้ากับข้อต่อเกลียวใน ½″ ให้ตัววาล์วตั้งอยู่ในถ้วย และปรับความสูงจนน้ำตัดที่ระดับลึก 3–4 ซม. ในราง
6. ต่อข้องอ 90° และท่อ ½″ ไปยังท่อน้ำจากภายนอก

## 04การติดตั้งใช้งาน

- ตั้งรางให้ได้ระดับ น้ำจะได้ลึกเท่ากันตลอดราง
- ยึดรางด้วยขาตั้งหรือแคล้มป์ทุกระยะ 1–1.5 ม.
- ควรมีรางน้ำอย่างน้อย 2 เส้นต่อไก่ 100 ตัว
- ล้างรางสัปดาห์ละ 1–2 ครั้ง และตรวจวาล์วลูกลอยสม่ำเสมอ

## 05ใช้กับแบบเล้า 4 ล็อก

- ราง 4.80 ม. ทำจากท่อ 4.00 + 0.80 ต่อด้วยข้อต่อตรง 2″
- วางนอกเล้า ห่างผนัง 0.15 ขอบรางสูงประมาณ 0.30 จากพื้น
- วาล์วลูกลอยอยู่ในถ้วยพักน้ำปลายรางฝั่งท่อน้ำเข้า

คู่มือคิดราง 1 เส้นต่อไก่ 20–30 ตัว ราง 4.80 ม. เทียบได้ราว 2.5 เส้นของราง 2 ม. รองรับไก่ได้ประมาณ 60–70 ตัว ล็อกละ 100 ตัวจึงควรเพิ่มรางอีก 1 เส้นภายในล็อก หรือเพิ่มนิปเปิล
