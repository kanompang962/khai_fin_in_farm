ผ่านสเปกวาล์ว (≥0.010)

ใช้ได้อีก (หน้าร้อน)**3.6 วัน**

## 02ทางเดินน้ำ

1. ประปา ½″ → บอลวาล์ว → ลูกลอยก้าน ¾″ ในถัง
2. ทางออกถัง ¾″ → บอลวาล์ว → ยูเนียน → ลงพื้น
3. กรองตะกอน Y → วาล์วเมน → สามทางแยกเหนือ/ใต้
4. เมนเหนือเลี้ยงล็อก A, B · เมนใต้อ้อมหัวเล้าเลี้ยงล็อก C, D
5. แต่ละล็อก: สามทาง → บอลวาล์ว ½″ → ขึ้นข้องอ → วาล์วลูกลอยมินิในถ้วยพักน้ำ → รางน้ำ

## 03แรงดัน

วาล์วมินิรับแรงดัน 0.01–1.5 MPa ทางเข้าวาล์วสูงจากพื้น 0.35 ม. แท่นถัง 1.20 ม. ให้หัวน้ำ 1.05–2.07 ม. (0.010–0.020 MPa) ผ่านสเปกตลอดจนน้ำถึงทางออกถัง

เลื่อนแถบระดับน้ำในกรอบซ้ายบนเพื่อดูแรงดันที่วาล์วราง

## 04ตำแหน่ง

- ถังอยู่มุมตะวันออกเฉียงเหนือ ห่างผนังตะวันออก 2.2 ม. ห่างผนังเหนือ 1.8 ม.
- ท่อเมนเดินห่างผนังเล้า 0.50 ม. ช่วงหน้าประตูตะวันออกฝังลึก 0.30 ม.
- ถ้วยพักน้ำและวาล์วอยู่ปลายรางฝั่งตะวันออกของทุกราง
