# ไข่ฟินอินฟาร์ม — Egg Farm 3D Simulation

เว็บจำลองฟาร์มไก่ไข่แบบ 3D (low-poly สร้างด้วยโค้ดทั้งหมด) จำลองวงจรงานประจำวัน:

ให้อาหาร (06:00) → ไก่ออกไข่ + มูลใต้กรง → เก็บไข่ (09:00) → คัดเบอร์ตามน้ำหนัก + เรียงแผง (11:00)
→ ขนขึ้นรถส่งหน้าร้าน (13:00) → ขายให้ลูกค้าตามราคาเบอร์ (14:00–20:00) → เก็บมูลทุก 2 วัน (16:00) → สรุปยอด (23:59)

## เริ่มใช้งาน

```bash
npm install
npm run dev      # http://localhost:5173
npm run test     # unit test ของ simulation engine
npm run build    # build static ไปที่ dist/ (deploy ได้ทุกที่: Vercel, Netlify, GitHub Pages)
```

## ค่าเริ่มต้น
โรงเรือน 1 หลัง ไก่ 100 ตัว (อายุ 24 สัปดาห์) · พนักงาน 1 คนทำทุกอย่าง (ให้อาหาร เก็บไข่ คัดไข่ ขาย เก็บมูล)
· ไม่มีหน้าร้าน ลูกค้ามาซื้อที่จุดขายหน้าฟาร์ม (เปลี่ยนเป็น “ส่งรถไปขายที่หน้าร้าน” ได้ในตั้งค่า › การขาย & ลูกค้า)
· 1 วันจำลอง = 5 นาทีที่ความเร็ว 1×
· เบอร์ไข่: 0 (≥70 ก.), 1 (65–69), 2 (60–64), 3 (55–59), คละ (ต่ำกว่า 55 ก. หรือบุบ/แตก)
· ขายได้ทั้งเป็นแผง (30 ฟอง) และเป็นฟอง — ลูกค้าครึ่งหนึ่งซื้อเป็นฟองครั้งละ 6–20 ฟอง สต็อกนับเป็นฟอง (แผงไม่เต็มก็ขายได้)

## ความสามารถ
- 3D: โรงเรือน กรงตับ A-frame รางอาหาร (ระดับอาหารลดตามเวลา) nipple drinker ไก่ ไข่บนรางรับไข่ มูลไก่สะสม ไซโลอาหาร ถังน้ำ
  จุดคัดไข่ แผงไข่แยกสีตามเบอร์ รถขนไข่ หน้าร้าน ลูกค้า พนักงานเดินทำงานตามตาราง กลางวัน/กลางคืน
- ควบคุมเวลา: 1× / 3× / 8× / 30× / 120×, หยุด (Space), ข้ามเวลา +1 วัน / +7 / +30 / +1 ปี
- ตั้งค่า: จำนวนโรงเรือน, จำนวนไก่, อาหาร (กรัม/ตัว/วัน + ราคา), ราคาขายต่อแผงและต่อฟองแยกตามเบอร์, เกณฑ์น้ำหนักเบอร์ 0–3 + คละ,
  พนักงาน/ค่าแรง, ค่าน้ำไฟ, รถ/ค่าขนส่ง, ราคามูลไก่, ลูกค้า/วัน ฯลฯ
- ขยายฟาร์มอัตโนมัติ (ตั้งค่า › ขยายฟาร์มอัตโนมัติ): สร้างโรงเรือนใหม่พร้อมลงไก่ทุก N เดือน/ปี จนถึงจำนวนโรงเรือนสูงสุด
  และกันเงินซื้อไก่รอบถัดไปเป็นรายจ่ายรายวัน “กันเงินซื้อไก่รอบถัดไป” แล้วนำไปจ่ายค่าไก่ตอนขยาย (ไม่นับซ้ำ)
- สถานะพนักงาน: ป้ายสีพร้อมไอคอน งาน รายละเอียด แถบความคืบหน้า และงานถัดไป ทั้งในฉาก 3D และแถบด้านบน
- จบวัน (23:59) หยุดเวลาและขึ้น popup สรุปประจำวัน: การผลิต การขายแยกเบอร์ รายรับ–รายจ่าย กำไรสะสม เหตุการณ์ (ปิดได้ที่ปุ่ม “สรุปสิ้นวัน”)
- ตั้งค่าแต่ละหมวดมีปุ่ม “คืนค่าเริ่มต้นหมวดนี้” แยกกัน
- สรุปรายงาน: รายวัน / รายเดือน / รายปี / รายรุ่น พร้อมกราฟและดาวน์โหลด CSV
- บันทึกอัตโนมัติใน localStorage · คีย์ลัด H = ซ่อนแผง, Esc = ยกเลิกการเลือก

## โครงสร้าง
- `src/sim/` — simulation engine (TypeScript ล้วน, deterministic ด้วย seeded RNG, ไม่ขึ้นกับการ render)
  - `engine.ts` event ประจำวัน, `flock.ts` โค้งการไข่ตามอายุ, `grading.ts` คัดเบอร์, `ledger.ts` สรุป วัน/เดือน/ปี/รุ่น
- `src/scene/` — 3D ด้วย three.js + @react-three/fiber + drei (`layout.ts` คำนวณตำแหน่งคน/รถจากเวลาจำลอง)
- `src/ui/` — แผงควบคุม, ตั้งค่า, รายงาน (Tailwind + Recharts)
- `src/state/useSimStore.ts` — Zustand store + game loop + บันทึกข้อมูล

## สมมติฐานของแบบจำลอง (แก้ได้ในหน้าตั้งค่า)
- อัตราการไข่ 78% (ตั้งค่าได้) — ไก่สาวเริ่มไข่ 18 สัปดาห์ ถึงอัตรานี้ที่ 21 สัปดาห์ ปลดระวางที่ 80 สัปดาห์
- น้ำหนักไข่เฉลี่ยเพิ่มตามอายุ ~50 → 64 กรัม · ให้อาหารต่ำกว่า ~110 ก./ตัว/วัน ไข่น้อยลงและฟองเล็กลง
- ราคาขายสูงกว่าราคาตลาดอ้างอิง → ลูกค้าน้อยลง · ไข่ค้างเกินอายุบนชั้นขายถูกทิ้ง
- ต้นทุนส่วนกลาง (ค่าแรง ขนส่ง แผงไข่) ปันส่วนเข้าแต่ละรุ่นตามสัดส่วนไข่
